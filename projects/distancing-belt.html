How it works

I developed a wearable belt as a school-level engineering project. The prototype uses four ultrasonic sensors mounted around the belt to detect nearby objects or people and monitor distance. An Arduino Mega is the main microcontroller: it reads the sensor data and triggers an alert when an object comes within the defined distance range.

Key highlights

  • Designed and built a wearable prototype for maintaining social distance.
  • Integrated four ultrasonic sensors for multi-directional distance detection.
  • Programmed an Arduino Mega to read and process sensor data.
  • Worked on hardware integration, sensor placement, wiring, and embedded programming.
  • Developed as part of the INSPIRE Awards programme and the ATL Marathon during school.
